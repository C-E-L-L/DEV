# DICOM 컬러맵 뷰어

일반 웹 브라우저에서 여러 DICOM 영상의 명암 정규화와 컬러맵을 비교하고, 파일별 설정과 ROI를 저장한 뒤 결과를 PNG/JPG 또는 일괄 ZIP으로 내려받는 독립 웹 서비스입니다.

## 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 처음 한 번 의존성을 설치합니다.

```powershell
python -m pip install -r requirements.txt
```

이후에는 아래 명령만 실행하면 됩니다.

```powershell
python app.py
```

서버가 시작되면 기본 브라우저에서 `http://127.0.0.1:8501`이 자동으로 열립니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

## 사용법

1. 왼쪽에서 여러 DICOM 파일 또는 폴더를 선택합니다. 폴더 선택은 하위 폴더의 `.dcm`과 `.dicom` 파일까지 포함합니다. 동일한 픽셀 영상이 발견되면 중복을 제외할지 모두 불러올지 한 번 확인합니다.
2. 파일 목록에서 작업할 파일을 선택하고 명암 정규화 방식, 컬러맵, 감마와 배경 임계값을 조절합니다.
3. `현재 파일 설정 저장`을 누르면 파일 이름 옆 상태가 `저장됨`으로 바뀝니다. 저장된 설정은 같은 파일을 다시 불러올 때 복원됩니다.
4. 컬러 스케일 아래의 `ROI 라벨링`을 누르면 확대 편집기에서 다각형·타원 ROI를 그리고 라벨을 지정할 수 있습니다. 그리기 도구는 ROI를 완성한 뒤에도 유지되며, 기존 ROI의 내부·선·조절점 위에서는 해당 ROI 이동·조정이 우선되고 바깥에서는 같은 도구로 다음 ROI를 그립니다. 라벨 목록은 편집기에서 추가하거나 이름을 바꿀 수 있습니다.
5. 파일별 다운로드 버튼으로 선택한 DICOM의 컬러 결과를 내려받습니다. ROI 선은 이미지에 포함되지 않으며 `현재 VIA JSON`으로 좌표 정보를 별도 내려받습니다.
6. `전체 변환 다운로드`에서 저장된 파일만 또는 모든 파일을 선택해 일괄 ZIP을 생성하거나, `전체 ROI VIA 다운로드`로 저장된 ROI와 기준 PNG를 묶어 내려받습니다.

파일 상태는 `미저장`, `수정됨`, `저장됨`, `오류`로 표시되고 저장된 ROI 개수는 별도 배지로 표시됩니다. 계정, 작업 목록, 컬러 설정과 ROI는 `user_data/colorizer.db`에 저장되고 원본 DICOM은 `user_data/uploads`에 계정별로 보관됩니다. 페이지나 서버를 다시 열어도 같은 계정으로 로그인하면 기존 작업을 이어갈 수 있습니다.

정규화된 흑백 영상은 명암 반전이 기본으로 켜져 있어 배경이 흰색이고 강도가 높을수록 검정색으로 표시됩니다. 이 반전은 컬러 결과에는 적용되지 않습니다.

## Docker 배포

루트 `docker-compose.yml`의 `colorizer` 서비스는 CELL의 MySQL 및 Spring 백엔드와 연결되지 않습니다. SQLite DB와 원본 파일은 전용 `colorizer-data` 볼륨에만 저장됩니다. 계정별 기본 저장 한도는 10GB이며 `COLORIZER_USER_STORAGE_LIMIT_GB`로 조정할 수 있습니다. 운영 환경에서는 `.env`에 충분히 긴 `COLORIZER_SECRET_KEY`를 설정하면 기존 `https://cell.cbnu.ac.kr/colorizer/` 경로로 서비스됩니다. 별도의 DNS나 TLS 인증서는 필요하지 않습니다.

내보낸 PNG/JPG에는 원본 DICOM 메타데이터가 포함되지 않습니다. 컬러맵 결과는 시각화용이며 의료적 판단을 대체하지 않습니다.

### MySQL 실행 SELECT 범위(비밀값을 제외한 재현식)

Docker 내부 환경변수 `MYSQL_ROOT_PASSWORD`를 `MYSQL_PWD`에 연결해 인증했다. 실제 값은 출력/저장하지 않았다. 예시 명령을 운영 DB 변경 명령으로 확대하지 않는다.

```sql
SELECT TABLE_NAME,COLUMN_NAME,COLUMN_TYPE,IS_NULLABLE,COLUMN_DEFAULT,COLUMN_KEY,EXTRA
FROM information_schema.COLUMNS WHERE TABLE_SCHEMA='celldb';
SELECT TABLE_NAME,COLUMN_NAME,REFERENCED_TABLE_NAME,REFERENCED_COLUMN_NAME
FROM information_schema.KEY_COLUMN_USAGE
WHERE TABLE_SCHEMA='celldb' AND REFERENCED_TABLE_NAME IS NOT NULL;
SELECT TABLE_NAME,INDEX_NAME,NON_UNIQUE,SEQ_IN_INDEX,COLUMN_NAME
FROM information_schema.STATISTICS WHERE TABLE_SCHEMA='celldb';
SELECT TABLE_NAME,CONSTRAINT_NAME,UPDATE_RULE,DELETE_RULE
FROM information_schema.REFERENTIAL_CONSTRAINTS WHERE CONSTRAINT_SCHEMA='celldb';
SELECT TRIGGER_NAME FROM information_schema.TRIGGERS WHERE TRIGGER_SCHEMA='celldb';
SELECT ROUTINE_NAME FROM information_schema.ROUTINES WHERE ROUTINE_SCHEMA='celldb';
```

SQLite는 `SELECT type,name,tbl_name,sql FROM sqlite_master ORDER BY type,name`만 실행했다. read-only관측의 정확시각/DB스냅샷ID는별도없으며현재스키마구조의근거로만사용한다.

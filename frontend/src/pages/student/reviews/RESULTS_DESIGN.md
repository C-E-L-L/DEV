# 학생 결과 확인·세포별 분석

## 목적과 범위

기존 학생 콘솔 안에서 결과 확인 → 오답 원인 탐색 → 실제 사진 복습으로 연결한다.
교수·관리자·채점 API와 제출 기록은 변경하지 않는다. 공개된 학생 본인의 ReviewCell만 사용한다.

## 과제별 결과

- 기존 과제/진단평가 단위를 유지한다. 현재 과제 제목으로 표시하며, 검색·유형 필터와 결과/오답 바로가기를 제공한다.
- 상세는 제목 옆에 정답률만 표시하며, 중복되는 통계 카드는 두지 않는다. 도말·세포 목록과 선택한 세포 카드의 높이를 맞추고, 작은 세포 사진 왼쪽/답 비교 오른쪽으로 배치한다. 원본 도말은 펼쳐볼 수 있다.
- 도말은 한 장이어도 목록에 표시한다. 진단평가는 도말이 없는 세포 단위이므로 별도로 처리한다.
- 정답/오답/모르겠어요/채점 대기 순서의 네 필터를 선택한 과제 안에서 적용한다. 기본은 정답이며, 정답이 없으면 내용이 있는 첫 필터로 연다. 특정 세포 딥링크는 그 세포에 맞는 필터로 연다. 도말 목록, 세포 목록, 이전·다음 이동도 필터를 따른다.
- 필터에 맞는 세포가 없으면 빈 상태를 표시하며, 다른 범위의 세포로 자동 전환하지 않는다.
- Dashboard의 review/cell/focus=wrong/view=wrong 딥링크를 유지한다. 분석에서 상세를 열고 돌아와도 분석 조건과 표시 개수를 유지한다.

## 세포별 분석

1. 동물 종을 하나 선택한다. 선택한 종 안에서 전체 과제 또는 특정 과제로 범위를 좁힌다.
2. 채점된 응답 수, 정답률, 오답 수, 채점된 모르겠어요 수, 채점 대기를 구분한다.
3. 정답 유형별로 문항 수/정답/오답/모르겠어요/정답률을 집계한다. ‘Band가 정답인 문항 N개 중 M개 오답’의 의미이다.
4. 오답 수 내림차순, 같은 오답 수에서는 문항 수 내림차순으로 표시한다. 5문항 미만은 표본 수 안내를 표시한다. 이는 유의성 판정 기준이 아니라 UI 안내 기준이다.
5. 잘못 고른 분류명 → 공개된 정답 조합을 횟수와 함께 표시한다. 모르겠어요는 분류명 혼동 조합에 넣지 않는다.
6. 유형의 ‘오답 N개 보기’를 누르면 해당 행 바로 아래에 오답 사진을 펼친다. 같은 버튼으로 접고 다른 유형을 누르면 그 행 아래로 전환한다. 조합/모르겠어요는 아래 복습 영역으로 좁힌다. 사진 선택 시 과제 상세의 그 세포로 이동한다. 한 번에 12개씩 표시한다.

## 수치의 정의

- graded = isCorrect가 true 또는 false인 응답 수. 채점 대기는 분모에서 제외한다.
- 정답률 = correct / graded × 100, 정수 반올림. graded가 0이면 ‘—’이다.
- 모르겠어요도 채점 후에는 오답에 포함되므로 오답 수와 별도로 더하지 않는다.
- 미응답은 ReviewCell에 없을 수 있으므로 상단의 응답/전체 문항 수로 안내하며 임의의 세포를 생성하지 않는다.
- 종별 키와 정답 유형을 함께 사용해 개·고양이의 동일 분류명을 섞지 않는다.
- 과제 난도·분포가 다르므로 ‘실력 향상’, ‘취약 확정’, AI 진단, 임의의 형태학적 해설을 생성하지 않는다. 관측된 수치와 문항 수만 제시한다.

## 검증

분석 도메인 테스트에서 채점 대기 제외, 모르겠어요 중복 집계 방지, 종별 분리, 정답 유형별 분모, 오답 조합 방향, 특정 과제/세포 인덱스 유지와 빈 결과를 확인한다.
기존 학생 대시보드·사이드바·분류 사진 확대·화질 조정 기본 펼침은 보존한다.

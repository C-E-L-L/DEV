참가자 입력
이름을 입력하고 게임 시작을 누릅니다. 이름을 비워두면 자동으로 번호가 붙어요.
2
게이지 멈추기
Space 또는 멈추기 버튼으로 움직이는 마커를 원하는 위치에 세웁니다.
3
점수 계산
폭탄 구간에 가까울수록 높은 점수 (최대 100점). 멈출수록 배수가 올라갑니다.
4
한 번 더 vs 챙기기
멈춘 뒤 선택합니다. 한 번 더는 폭탄이 커지며 배수 증가 — 터지면 이번 턴 점수 전부 소멸. 챙기기는 현재 점수를 그대로 확정.
